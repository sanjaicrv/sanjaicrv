## Featured Projects

### 🤖 AI-Powered Jewellery Defect Detection System

Computer vision system for automated detection of missing gemstone defects
in jewellery images using **YOLOv8**.

- Built an end-to-end computer vision pipeline using **YOLOv8 Nano**
- Worked with a **671-image annotated dataset** using Roboflow
- Implemented image preprocessing, augmentation, transfer learning, training,
  and model evaluation
- Achieved **89.64% Precision, 56.76% Recall, and 65.53% mAP@50**
- Implemented real-time inference using **PyTorch and OpenCV**
- Achieved approximately **15.5 ms inference latency (~64 FPS)** on an
  NVIDIA GTX 1650 GPU

**Tech Stack:**
`Python` `YOLOv8` `PyTorch` `OpenCV` `Roboflow` `Computer Vision`

🔗 [View Project](https://github.com/sanjaicrv/AI-Powered-Jewellery-Defect-Detection-System-for-Stone-Missing-using-YOLO-v8)
